# Simulation Reproducibility Materials

This folder contains all code and saved results needed to reproduce the simulation
study reported in Section 6 of the manuscript, specifically:

- **Table 1** (`\label{tab:bias_vr_full}`): Simulation results for calibration estimators
  under different surrogate prediction models (n₂ = 6,000).
- **Table 2** (`\label{tab:simulation_theta}`): Comparison of calibration and plug-in
  (influence-function) estimators (n₂ = 6,000).
- **Figure 3** (`\label{fig:3}`): Relative variance of calibration estimators for
  β_{x₃} and β_{x₁:x₃} across increasing external sample sizes
  (n₂ ∈ {2,000, 6,000, 20,000}).

## Slow Route (Optional — verification only)

The optional rerun scripts regenerate the Monte Carlo simulation from scratch.
**This is very slow** (Script 04: several hours; Script 05: many hours due to
fitting `glm()` on N = 1,000,000 observations per iteration).

```r
source("code/04_rerun_table1_simulation_optional.R")   # optional
source("code/05_rerun_table2_simulation_optional.R")   # optional
```

Rerun outputs go to `results/rerun_outputs/` and do **not** overwrite the
canonical results in `results/canonical/`.

**Important:** Rerun outputs are not expected to exactly reproduce the canonical
manuscript tables — see the section on reproducibility below.

## Canonical Results vs. Rerun Outputs

The manuscript tables were produced from canonical Monte Carlo summaries saved in
`results/canonical/`. These are the authoritative source for the manuscript numbers.

The optional rerun scripts (04–05) exist for transparency and independent
verification of the computational procedure. However, rerun results may differ
from the canonical values for the following reasons:

1. **Sanitized vs. historical seeds**: The optional rerun scripts sanitize the
   seed file into valid positive integers before calling `set.seed()`. The
   historical long simulation runs used less-clean seed/path handling. The
   sanitized seeds are deterministic within a fixed R environment, but may
   yield different draws than the original runs.

2. **Monte Carlo variation**: Even with the same algorithmic setup, 1,000
   replications of a stochastic simulation will show finite-sample variation.
   Small Monte Carlo differences in Bias(%), VR, CR, and RelVar do not affect
   the conclusions of the paper.

3. **Post-processing differences**: The canonical Table 2 files were manually
   compiled from raw simulation output. Minor differences in row selection or
   rounding may exist.

For exact reproduction of the manuscript tables, always use the **Fast Route**
(Scripts 01–03) from the saved canonical results.

## Seed File

`code/helper_functions/seed.txt` contains 1,000 rows and 2 columns (`seed1`,
`seed2`), one row per Monte Carlo replicate.

The original seed file stores numeric seed values, including decimal and negative
entries (e.g., `43280.79`, `-42007.74`). The cleaned optional rerun scripts
(04 and 05) sanitize these values into valid positive integers before calling
`set.seed()`. Specifically, each value is truncated to an integer via `trunc()`
and the absolute value is taken; zero is mapped to 1. This makes reruns
deterministic within a fixed R environment. However, the cleaned reruns may not
exactly reproduce the historical canonical summaries because the original long
runs used earlier seed/path handling and post-processing.

## Surrogate Model Note

In the simulation code, surrogate covariates are indexed as `m1` and `m2`,
which correspond to the manuscript labels as follows:

| Code | Parameter `a` | Correlation ρ | Manuscript label |
|------|---------------|---------------|-----------------|
| m1   | 0.67          | ≈ 0.80        | X₃*(2)          |
| m2   | 1.55          | ≈ 0.50        | X₃*(1)          |

A smaller `a` value produces less distortion of X₃, yielding a higher correlation
between the expensive covariate X₃ and its surrogate.

## Note on Bias(%) Formula

**Table 1** Bias(%) is computed as:

```
Bias(%) = (mean_estimate - true_FP_glm) / beta_sim_true × 100
```

where `true_FP_glm` is the regression coefficient from fitting logistic regression
on the full N = 1,000,000 population, and `beta_sim_true` = (1.0, 0.5, 0.5, 0.2)
is the simulation-setting parameter vector for (β_{x₁}, β_{x₂}, β_{x₃}, β_{x₁:x₃}).

The denominator uses the simulation-setting value (not `true_FP_glm`) to reproduce
the manuscript Table 1 numbers. The two are close but not identical (e.g.,
`true_FP_glm` for x₁ ≈ 1.009 vs. simulation-setting 1.0) because cluster effects
shift the finite-population regression slightly.

**Table 2** Bias(%) uses the same relative-bias definition but the canonical
result file stores the relative bias `(mean - true_FP_glm) / true_FP_glm` as a
fraction directly, so `Bias(%) = stored_value × 100`.
